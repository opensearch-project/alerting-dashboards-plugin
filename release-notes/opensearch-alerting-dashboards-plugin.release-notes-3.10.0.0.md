## Version 3.10.0 Release Notes

Compatible with OpenSearch and OpenSearch Dashboards version 3.10.0

### Features

* Show monitor creator from resource sharing in the monitors list ([#1537](https://github.com/opensearch-project/alerting-dashboards-plugin/pull/1537))
* Show data streams in the monitor index picker for local and cross-cluster monitors ([#1518](https://github.com/opensearch-project/alerting-dashboards-plugin/pull/1518))

### Bug Fixes

* Fix monitor search for hyphenated names, PPL monitor card gating for unsupported data sources, Notifications plugin detection on probe failure, and create-form reset on data source change ([#1523](https://github.com/opensearch-project/alerting-dashboards-plugin/pull/1523))
* Make lookback window editable when editing a PPL monitor ([#1516](https://github.com/opensearch-project/alerting-dashboards-plugin/pull/1516))
